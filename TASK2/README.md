# Панель путешественника — Припять

## Тема проекта
Интерактивная панель путешественника в стилистике заброшенной Припяти: тёмный интерфейс, индустриальный дизайн и жёлтые акценты. Панель содержит виджеты задач, погоды и валютных курсов.

## Запуск
1. Поместить файлы проекта в папку `TASK2`.
2. Открыть терминал в этой папке.
3. Выполнить команду:

   ```bash
   py -m http.server 8000
   ```

4. Открыть в браузере `http://localhost:8000`.

## Источники API
- **Open-Meteo** — получение данных о погоде: https://open-meteo.com/
- **Frankfurter API** — получение валютных курсов: https://frankfurter.dev/

## Нейросеть
При разработке проекта использовалась нейросеть DeepSeek для генерации и исправления HTML, CSS и JavaScript, проектирования интерфейса, поиска ошибок и улучшения пользовательского взаимодействия.

## Полезные промпты
1. «Создай адаптивный тёмный интерфейс дашборда в стиле заброшенной Припяти с жёлтыми акцентами».
2. «Реализуй виджет погоды на JavaScript с использованием Open-Meteo API и обработкой ошибок загрузки».
3. «Проверь HTML, CSS и JavaScript на ошибки, исправь обработчики событий и сделай интерфейс адаптивным».
