
# Маленькое путешествие

Небольшой браузерный платформер на HTML, CSS, Canvas и ванильном JavaScript.
Тема — милая low-poly эстетика, пастельные цвета и маленькое приключение.

## Запуск

1. Скачайте или скопируйте все файлы проекта в одну папку.
2. Откройте папку в Visual Studio Code.
3. Запустите `index.html` через расширение Live Server.
4. Нажмите «Начать путешествие».

ES-модули могут не работать при открытии файла напрямую через `file://`,
поэтому рекомендуется использовать локальный HTTP-сервер. Устанавливать
npm, сборщики или игровой движок не требуется.

## Файлы

- `index.html` — структура страницы и интерфейс.
- `style.css` — оформление и адаптация под мобильные устройства.
- `main.js` — запуск игры и обработчики кнопок.
- `Game.js` — уровень, игровой цикл, предметы, состояния и отрисовка.
- `Player.js` — персонаж, движение, гравитация и прыжок.
- `input.js` — клавиатура и сенсорное управление.
- `collision.js` — столкновения с платформами.

## Управление

- A / D или стрелки влево и вправо — движение.
- Space / W / ↑ — прыжок.
- Сенсорные кнопки — на телефоне.
- «Пауза» — остановка игры.
- «Заново» — перезапуск уровня.

## Игровая цель

Собрать три кристалла, избежать шипов и добраться до домика.
Для победы необходимо собрать все три предмета. При падении или
касании опасной зоны игрок проигрывает.

Лучший результат сохраняется в `localStorage`.

## Используемые технологии

HTML5, CSS3, JavaScript ES Modules, Canvas API,
requestAnimationFrame и localStorage.
Нейросеть DeepSeek.

## Полезные промпты для развития

1. Добавь второй уровень с новыми платформами и увеличенной сложностью.
2. Добавь звуковые эффекты прыжка, сбора кристаллов и победы.
3. Добавь меню выбора уровней и сохранение прогресса.
