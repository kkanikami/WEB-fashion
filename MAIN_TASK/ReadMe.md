# Тихий бор — учебное бронирование домиков

**Тема.** Загородные дома-бунгало в тихом лесу у озера. Пользователь выбирает домик на изометрической схеме посёлка, указывает гостей и ночи, получает сумму и оформляет учебную бронь.

> **Учебное демо:** бронирования сохраняются только в этом браузере. Реальная бронь, оплата, регистрация и сервер не используются.

## Запуск

Проект на HTML, CSS и ванильном JavaScript, без сборки и npm. Из-за ES-модулей `index.html` нужно открывать через сервер, а не двойным щелчком:

```
python3 -m http.server 8000
```

Затем откройте http://localhost:8000. Сайт также публикуется как есть на GitHub Pages.

## Структура

- `index.html` — разметка
- `style.css` — оформление (бело-голубо-фиолетовая палитра, свечение, шрифт Nunito)
- `js/data.js` — данные о 8 домах
- `js/storage.js` — сохранение в `localStorage`
- `js/map.js` — рисование изометрической схемы
- `js/app.js` — выбор, фильтры, форма, брони

## Функции

- Изометрическая схема с 8 нарисованными домиками и список тех же домов из одних данных.
- Статусы «свободен», «выбран», «занят» подписаны текстом и значками, не только цветом. Занятый дом выбрать нельзя.
- Фильтры по числу гостей и максимальной цене; схема и список меняются одновременно. Если фильтр скрыл выбранный дом, выбор сбрасывается.
- Карточка дома с формой: гостей от 1 до вместимости, ночей от 1 до 30. Сумма = цена за ночь × ночи, обновляется при вводе. Неверные значения показывают ошибку, бронь не создаётся.
- Подтверждение создаёт одну бронь (повторное нажатие дубликата не даёт). «Мои брони» сохраняются после обновления страницы; отмена освобождает дом.
- Сброс демо с подтверждением (удаляется только ключ приложения). Повреждённые данные и запрет сохранения показывают сообщение.
- Работает на телефоне и с клавиатуры: дома можно выбирать кнопками списка и на схеме (Tab, Enter, пробел), фокус виден.

## Ограничения

Дом бронируется целиком до отмены, без календаря дат и пересечений. Данные хранятся только в `localStorage` этого браузера, их нельзя перенести на другое устройство. Два дома заняты изначально для демонстрации.
