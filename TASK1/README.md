# Портфолио Вероники Пеккаревой

Адаптивный сайт-портфолио студентки направления «Прикладная информатика в дизайне». Сайт представляет учебные и творческие проекты в области 3D, графического дизайна и иллюстрации.

## Технологии

- HTML5
- CSS3
- JavaScript без сторонних библиотек и фреймворков

## Как открыть сайт локально

1. Скачайте или клонируйте репозиторий.
2. Убедитесь, что `index.html`, `style.css` и `main.js` находятся в одной папке.
3. Проверьте наличие папки `images` с изображениями проектов.
4. Откройте `index.html` в браузере.

Установка дополнительных программ и сборка проекта не требуются.

## Возможности JavaScript

- **Фильтрация проектов:** категории «Все», «3Д», «Дизайн», «Иллюстрация» и «Фотография».
- **Пустая категория:** отображается сообщение, если в выбранной категории нет работ.
- **Переключение темы:** светлая и тёмная темы с сохранением выбора в `localStorage`, если браузер разрешает хранение данных.
- **Мобильное меню:** открытие и закрытие кнопкой, закрытие после перехода по ссылке и по клавише `Escape`.
- **Доступность:** состояние мобильного меню передаётся через `aria-expanded`, для клавиатурной навигации предусмотрен видимый фокус.
- **Год в подвале:** автоматически обновляется.

### Примеры промптов

**1. Создание сайта-портфолио**

Запрос: «Создай сайт-портфолио на HTML, CSS и обычном JavaScript без React, npm и сборки. Используй адаптивный kawaii pink bento-дизайн. Разделы: обо мне, образование, навыки, проекты и контакты».

Результат: подготовлена структура сайта, оформление карточек и адаптивная сетка.

**2. Фильтрация проектов**

Запрос: «Добавь фильтр карточек проектов по категориям: 3Д, Дизайн, Иллюстрация и Фотография, а также кнопку “Все”. Реализуй на обычном JavaScript, сохрани оформление и показывай сообщение, если карточек нет».

Результат: добавлены переключаемые категории, выделение активной кнопки и сообщение для пустой категории.

**3. Темы и мобильная навигация**

Запрос: «Добавь переключатель светлой и тёмной темы с сохранением выбора в localStorage. Добавь мобильное меню с aria-expanded, видимым фокусом и закрытием по Escape. Сохрани остальные функции».

Результат: добавлены две цветовые темы и управление мобильной навигацией с клавиатуры.

Примеры отражают основные этапы работы над сайтом; перед сдачей следует проверить, что опубликованная версия соответствует фактическому содержимому проекта.
